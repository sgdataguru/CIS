# Contributing to Sentinel

1. Do not commit secrets, customer data, device credentials, voice recordings, SIM details, or production exports.
2. Use short-lived branches and pull requests against `main`.
3. Run `pytest` and `ruff check .` before requesting review.
4. Update feature, architecture, data contract, device, and operational documentation with code changes.
5. Changes involving AI guardrails, access control, retention, device security, firmware, or deployment require security and product review.
